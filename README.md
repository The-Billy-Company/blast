# blast

The composed face — the two questions that need both engines and CURRENT
bytes: `blast` (the live blast radius of a symbol — dependents,
dependencies, twins, ripple, comments, with no precomputed graph) and
`provenance` (quote attribution re-verified against live bytes).

Formerly the `irregex` binary; renamed so the `irregex` name belongs to
the library. Extracted from `billy/libs/kernels/irregex` (cut from
billy@ce430bbaab, PLAN v5 split). Depends on [`irregex`](../irregex),
[`relate`](../relate), and [`gist`](../gist) as sibling checkouts during
development.

Status: extraction snapshot — build wiring (module-qualified imports,
build.zig) is in progress.
